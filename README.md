# Cybertruck Animation

An eye-catching animated Cybertruck built using plain HTML, CSS and JavaScript.

[![Screenshot of the animation](./Screenshot%202024-08-22%20132001.png)](./Screenshot%202024-08-22%20132001.png)

Overview

This small project demonstrates how to create a smooth, lightweight vehicle animation (the Cybertruck) using only front-end web technologies. It is intended as a visual experiment and a learning resource for CSS animations and simple DOM-driven interactions.

Live preview

- Open `index.html` in your browser to see the animation.
- For a local web server (recommended if you want a proper origin), serve the folder with a simple static server: `npx http-server` or `python -m http.server` and visit http://localhost:8080 (or the port shown).

Features

- Pure HTML/CSS/JS implementation — no frameworks.
- Smooth animation and subtle interactivity.
- Single-file entry point (`index.html`) for easy experimentation.

Files

- `index.html` — main page and markup for the animation.
- `style.css` — styling and keyframe animations.
- `script.js` — small JavaScript for timing/interaction.
- `Screenshot 2024-08-22 132001.png` — project screenshot (shown above).
